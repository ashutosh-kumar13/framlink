GETTING STARTED IN 5 STEPS
═════════════════════════════════════════════════════════════════════════════

Step 1: Create virtual environment
  → python -m venv .venv

Step 2: Activate it
  → .\.venv\Scripts\Activate.ps1

Step 3: Install dependencies
  → pip install -r requirements.txt

Step 4: Run server
  → uvicorn app:app --reload

Step 5: Test it
  → Open browser: http://127.0.0.1:8000/docs
  → Or run: Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8000/optimize -ContentType 'application/json' -InFile sample_request.json

EXAMPLE FEATURES
═════════════════════════════════════════════════════════════════════════════

🌊 FLOODING DETECTION
  When: Heavy rain (>20mm) at low elevation (<100m)
  Effect: Routes add 40-80% extra travel time
  Driver Alert: "⚠️ CAUTION - Flooding risk at pickup location"

⛰️  LANDSLIDE DETECTION
  When: Heavy rain (>30mm) at high elevation (>300m)
  Effect: Routes add 80% extra travel time (DANGEROUS)
  Driver Alert: "🚫 DANGEROUS - Landslide risk. Consider alternative route"

❄️  COLD-CHAIN TRACKING
  When: Strawberry needs 4°C but it's 26°C outside
  Effect: Higher priority score (protect from spoilage)
  Driver Alert: "📦 Cold item - Minimize time in vehicle"

⏰ DEADLINE TRACKING
  When: Order due in 8 hours (tight!)
  Effect: Higher priority score
  Driver Alert: "🚨 Tight deadline - Prioritize this delivery"
